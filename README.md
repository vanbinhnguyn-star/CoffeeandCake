Tên đề tài:
Xây dựng website bán cà phê và bánh ngọt tích hợp chức năng đặt hàng trực tuyến

Mục tiêu:
Xây dựng website thương mại điện tử chuyên biệt cho ngành hàng cà phê và bánh ngọt.
Cho phép khách hàng tìm kiếm, xem sản phẩm, đặt hàng trực tuyến, theo dõi trạng thái đơn hàng.
Xây dựng trang quản trị giúp chủ cửa hàng quản lý sản phẩm, đơn hàng, khách hàng và thống kê doanh thu.
Đảm bảo hệ thống hoạt động ổn định, giao diện thân thiện, responsive trên cả máy tính và thiết bị di động.

Phạm vi:
Đối tượng sử dụng: khách hàng cá nhân có nhu cầu đặt mua cà phê/bánh ngọt trực tuyến, và quản trị viên (chủ cửa hàng/nhân viên) vận hành cửa hàng.
Xây dựng cho một cửa hàng/chuỗi quy mô nhỏ (single-tenant), tập trung vào toàn bộ quy trình đặt hàng trực tuyến: duyệt sản phẩm → giỏ hàng → đặt hàng → theo dõi đơn.
Không bao gồm: tích hợp cổng thanh toán thực tế của ngân hàng/ví điện tử (mô phỏng hoặc dùng sandbox), tích hợp đối tác vận chuyển thứ ba, hỗ trợ đa chi nhánh hoặc đa ngôn ngữ trong phạm vi đồ án kỳ này.

Công nghệ dự kiến:
Frontend: Vue 3 (Composition API) + Bootstrap 5, giao diện responsive.
Backend: Node.js + Express.js, RESTful API theo mô hình MVC.
Cơ sở dữ liệu: MongoDB, sử dụng Mongoose ODM.
Xác thực: JSON Web Token (JWT), mã hóa mật khẩu bằng bcrypt.
Realtime: Socket.io cho thông báo trạng thái đơn hàng.
Công cụ hỗ trợ: Git/GitHub, Postman.
